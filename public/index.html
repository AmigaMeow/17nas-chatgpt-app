IPv6 Checker & Stats

Browser connectivity checks and IPv6 adoption statistics, inside ChatGPT.

What the app does

  • Checks reachability to a dedicated IPv6-only HTTPS probe and displays observed IPv4/IPv6 transports and HTTP request duration.
  • Estimates the country attributed to the browser request. VPNs and proxies may affect it.
  • Shows APNIC Labs global adoption, country rankings and snapshot dates, separately from eligible 17NAS country aggregates.
  • Provides a separate NAT test link for multiplayer and peer-to-peer troubleshooting. The card itself does not measure NAT type or diagnose a disconnection cause.

Private by design

Network requests require transient source-address processing. The App does not retain or display your IP address, ASN or precise city. Failed IPv6 probes remain unverified. HTTP request duration is not ping latency.

Use in ChatGPT

In a connected development installation, ask “Check my browser connection and IPv6 reachability” or “Show global IPv6 adoption and the APNIC country rankings.” Public directory availability depends on review.
