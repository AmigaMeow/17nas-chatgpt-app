# Privacy policy — IPv6 Checker & Stats

Draft for operator review. Operator: jiahui zhang. Contact: hello@17nas.com.

The App checks browser IPv6 connectivity and displays country attribution, aggregated 17NAS measurements and APNIC Labs rankings. Browser network requests necessarily carry a source address. The dedicated service processes that address transiently solely to estimate country-level attribution, evaluate protocol connectivity, and limit abuse. Source addresses are processed transiently as described above; they are not retained, returned to ChatGPT, or displayed. ASNs and city-level locations are not returned or displayed. Connection details are returned only by browser connection endpoints with no-store headers; our service does not persist or log them. IP address parameters remain prohibited. AI-host tool calls do not identify your browser connection.

No daily query counters or user accounts are collected. Minute-scoped IP HMACs are held only in process memory for request limiting, discarded at the next UTC minute and never logged or persisted. Their keys rotate each minute. No Cookie, LocalStorage, advertising identifier or persistent user identifier is used. Browser probe results, including protocol connectivity and HTTP request duration, are displayed and can be shared as result context with ChatGPT for subsequent responses. This context may remain in the conversation under OpenAI policies; the no-storage promise concerns our service, not ChatGPT conversation retention. Browser results are held only in the current card memory; they are not written to persistent widget state. Individual probe records are not retained by our service.

Our own aggregate source uses a rolling 30-day measurement window; the App receives only country aggregates, not raw records. The independent snapshot is replaced by an hourly export, cached for one hour, with last-good use limited to 24 hours. The App stores no daily personal records for 30 days. Its code cannot access website internal APIs or website storage. The website and separately installed MCP package have distinct processing practices.

The existing hosting and reverse-proxy providers necessarily handle network transport; their processing is subject to their policies. OpenAI handles conversations under its own policies. App process and Nginx access/error logging are disabled; provider-level security logs and backup retention still require operator verification before final privacy claims. We do not sell personal information or use it for advertising.

Where applicable under GDPR and CCPA/CPRA, contact hello@17nas.com to request access, correction, deletion, restriction, explanation, or exercise objection and complaint rights. Country aggregates cannot be attributed to a person; short-lived security records have no persistent identifier. We will explain what can be located without asking for unnecessary information. Security and service operation are the processing purposes; applicable legal bases and processor arrangements require operator review before public release.
